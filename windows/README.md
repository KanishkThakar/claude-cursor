# Claude Cursor for Windows

The Windows version was built and tested first (on 2026-11-15, in Calculator, Character Map and Notepad). It is the same idea as the Mac version: an orange "Claude" arrow that shows where Claude is acting while you keep your own mouse and keyboard.

**The source is being moved from the original Windows PC into this folder.** It is coming in the next commit. Watch or star the repo to get notified.

Planned contents:

| File | Purpose |
|---|---|
| `ghost.*` | Click-through, non-activating, topmost overlay that draws the cursor |
| `claude-cursor.*` | `start` / `move` / `click` / `say` / `stop` controller, same commands as macOS |
| `README.md` | Build and usage notes for Windows |
